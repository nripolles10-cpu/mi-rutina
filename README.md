# Mi Rutina

App de rutina de gimnasio (React). Ahora mismo es un único archivo, `ultimo.html`, que se abre en el navegador.

- `ultimo.html`: versión corregida en la Fase 1.
- `ultimo.original.html`: versión original, como referencia.
- `INFORME_FASE1.md`: informe de la auditoría.
- `tests/`: pruebas automáticas. Para lanzarlas: `npm install` y luego `npm test`. Para ESLint: `npm run lint`.

La Fase 2 convertirá la app en un proyecto Android con Capacitor.
